# Hive feedback

Report what goes wrong when you test [Hive](https://tryhive.dev), the MCP server that picks a tool for your agent,
says how it is likely to fail, calls it, and checks the result.

Open an issue with one of the forms:

- **Wrong pick**: Hive picked the wrong tool, stopped when a tool fit, or picked when it should have stopped.
- **Wrong verdict**: Hive judged a result wrongly, or its prediction was far off.
- **Something else**: errors, slow searches, confusing hints, ideas.

Or use the form at [tryhive.dev/feedback](https://tryhive.dev/feedback), which fills the report in for you.

This repository is public. Hive never stores your requests or results, so please don't paste them here either:
describe the request without names, emails or account numbers.
